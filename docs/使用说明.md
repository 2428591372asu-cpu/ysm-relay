# ysm-relay 使用说明

给玩家和服主看的。命令细节见 [ADMIN.md](ADMIN.md)，技术背景见 [02-YSM3.0接入点调研.md](02-YSM3.0接入点调研.md)。

## 这个 mod 解决什么

YSM 原本的模型分发是单向的：服务端放什么，客户端就能拿到什么。玩家想用自己的模型，得把文件发给服主、等服主放进目录、再等重扫。

ysm-relay 补上反过来的那一段：

```
玩家客户端 ──上传模型──> 服务端落盘 ──> YSM 自己重扫 ──> 自动分发给所有客户端
```

服务端收到后，YSM 原生的分发链路会把它接进去，其他人下次打开模型列表就能看到，**不需要重启服务器**。

## 安装

| 位置 | 需要装 |
| --- | --- |
| 服务端 | `ysm` 3.x + `ysm_relay` |
| 客户端 | `ysm` 3.x + `ysm_relay` |

两端 relay 版本要一致。只装了 YSM 的客户端仍能正常进服，只是没有上传按钮。

## 玩家：怎么上传

### 打开面板

两个入口：YSM 模型界面里的「上传模型」按钮，或热键 `U`。

面板顶部显示当前扫描目录，点「目录…」可以改成任意本地文件夹；「打开目录」会直接在资源管理器里打开它。

### 选文件与上传

- 支持 `.mxc`、`.ysm`、`.zip`、`.7z`
- 可以多选，按列表顺序串行上传
- 每个文件都能看到阶段：计算标识 → 询问服务端 → 分块发送 → 完成
- 预检只是提示：标了「预检未通过」的文件仍然可以上传，最终由服务端判定

### 上传之后

| 服务端模式 | 你会看到 |
| --- | --- |
| 审批模式 | 「已收下，等待服主审核」，服主批准后才入库 |
| 自动同意 | 不超过阈值直接入库；超过阈值转待审 |
| 全自动 | 不超过阈值直接入库；超过阈值直接拒绝 |

入库后由 YSM 重扫，模型出现在所有人的列表里。

### 自动上传

设置页「上传模型」栏里设一个自动上传目录，文件变化就会自动传。前提是服主开了「允许自动上传」，且当前不是审批模式。

## 玩家：管理自己的上传

设置页里三张表：

- **我的上传**：已入库的模型，可以删除
- **我的待审**：还在等服主处理的，可以撤回
- **待审队列**：仅服主/有审批权限的人可见

也可以直接用命令：

```
/relayme list
/relayme delete <模型> confirm
/relayme cancel <编号>
```

删除会同时清掉 YSM 的转换缓存和源文件，删完触发重扫。如果文件被 YSM 占用，会提示失败并要求重启服务端后再试。

## 服主：常用操作

```
/ysmrelay status                 看总览
/ysmrelay paths                  看目录与实际文件数（排障第一步）
/ysmrelay pending                看待审队列
/ysmrelay approve <编号> / reject <编号>
/ysmrelay delete <模型> confirm  删除并禁止再次上传
```

### 用界面管理模型

设置页最下面新增「模型管理」块：

- 「服主本地」分组排最前，之后是玩家分组，组名按 A–Z 排序
- 每行是一个模型，点一下变成「确认删除 xxx？」，5 秒内再点一次才会真删
- 顶部「刷新模型列表」重新拉取

删除走的是和命令同一条链路：清源文件 + 清 YSM 转换缓存 + 重扫。

完整命令与权限说明见 [ADMIN.md](ADMIN.md)。

## 常见问题

**点入口提示「功能不可用，因为这个服务器并没有安装 relay」**
服务端没装 relay。本模组用 Forge 的登录通道表判断，是确定性的结论，不是超时猜测。

**单人模式点入口没反应 / 提示不可用**
没开 LAN 的单人存档没有服务端，上传功能不存在。开 LAN 或用专用服务器。

**上传显示成功，模型列表里没有**
依次确认：是否还在待审（看「我的待审」）→ 服务端日志有没有 `上传模型成功 path=…` → 用 `/ysmrelay paths` 看上传根对不对 → 看 YSM 是否报了扫描错误（例如容器缺少内嵌预览）。

**custom 目录里文件不见了**
`custom` 是 YSM 的导入入口。YSM 导入后会把容器放进 `cache/converted`，源文件是否保留由 YSM 决定。判断模型在不在，要看 YSM 的模型列表，不是看目录。

**模型名显示成一长串十六进制**
旧版本用模型标识当文件名。1.2.7 起保留玩家原始文件名，重新上传即可。

**删除后模型又回来了**
`custom` 里还有同内容、不同文件名的副本，重扫时被重新导入。删掉副本，或用 `block` 限制。

**两端版本不一致**
上传通道按协议版本校验，混版会直接不可用（不影响进服）。两端换同一版 jar。

## 模型格式小抄

| 文件头 | 类型 | 谁负责解析 |
| --- | --- | --- |
| `EF BB BF YSGP 2` | 当前资产容器（.mxc） | YSM 直放，需要内嵌预览 |
| `EF BB BF YSGP` | 旧版 V3 加密 | YSM 源导入 |
| `YSGP` + 版本号 1/2 | 旧版原始归档 | YSM 源导入 |
| `PK` / `7z` | zip / 7z | YSM 源导入 |

relay 只负责把文件搬到服务端；解密、转码、建索引全部交给 YSM。
